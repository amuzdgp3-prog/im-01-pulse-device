# ИМ-01 — плата: схема, трассировка, файлы для производства

Ревизия A, 15.09.2026. Всё генерируется из одного файла `hardware/design.py`: схема, плата и перечень
не могут разойтись. Как пересобрать — в конце документа.

## Коротко

- Плата 80×55 мм, 2 слоя, 1.6 мм, 108 элементов, из них 90 монтируются. Всё на верхней стороне.
- Модем **Quectel EG800K-EU** (LTE Cat.1 bis, диапазоны B1/B3/B5/B7/B8/B20/B28).
- Проверки: ERC схемы — 0 ошибок; DRC платы — 0 нарушений; сверка платы со схемой — 0 расхождений.
  Состояние разводки — в конце документа.
- Комплектующие: около 840 ₽ на плату при партии 500 шт. (подробно — в
  [ИМ-01_перечень_комплектующих.xlsx](ИМ-01_перечень_комплектующих.xlsx)).
- Файлы для заказа на JLCPCB — `hardware/fab/`.

**Перед заказом партии в 500 штук плату должен посмотреть глазами инженер-схемотехник** (IM-01 §9
шаг 5: «плату на 500 шт не отправлять в производство без ревью глазами»). Сначала — 5–10 штук на пилот.

## Решения, принятые при разработке платы

1. **Модем EG800K-EU вместо Air780E.** У китайского Air780E нет диапазона B20 (800 МГц — покрытие в
   посёлках) и B7. У Air780EU документации нет в открытом доступе. EG800K-EU того же размера, с полной
   документацией Quectel, $4.80.
2. **Транслятор уровней TXS0102.** Логика EG800K — 1.8 В, MCU — 3.3 В. Сторона модема питается от его
   VDD_EXT: пока модем выключен, транслятор отключён и MCU не запитывает модем через линию.
3. **Преобразователь на 60 В** вместо MP1584 (тот держит только до 28 В) — по результатам симуляции шага 1.
4. **Три полимерных конденсатора 470 мкФ на VBAT** — у EG800K минимум 3.4 В (у Air780E было 3.3 В).
5. **Питание MCU через диод с отдельным накопителем.** Даёт ~50 мс работы после пропадания 12 В —
   этого хватает дописать счётчики в FRAM. Отдельный ключ отключения модема стал не нужен.
6. **Каждый вход на двух выводах MCU.** Аппаратный счётчик фронтов (TIM1/TIM3) считает без участия
   ядра — гарантия из §2. Захват времени фронтов с DMA (TIM16/TIM17) даёт проверку длительности ≥ 15 мс.
7. **Разъёмы монеты и купюры разные** (2 и 3 контакта). Каналы невозможно перепутать, а у них разный
   вес импульса.
8. **Отладочный UART модема на точки не выведен.** Его дорожки резали заливку питания модема.
   Прошивка модема обновляется через USB (TP9–TP12), как рекомендует Quectel.

## Разводка

Три цепи разведены по заданной геометрии и зафиксированы (IM-01 §9 шаг 5):

- **антенна** — прямая линия 1.0 мм от вывода 35 модема через R26 к U.FL, со строчкой переходных на
  землю вдоль неё;
- **коммутирующий узел преобразователя** — короткие широкие дорожки SW → дроссель и диод;
- **путь VBAT** — сплошная медная заливка от дросселя через все накопительные конденсаторы к выводам
  42/43 модема (задание требует ≥ 2 мм).

Остальное развёл Freerouting. Нижний слой — сплошная земля, слои сшиты переходными.

## Виртуальная модель

`sim/run_final.py` — одна схема ngspice на всё устройство с окончательными номиналами. Результаты — в
`sim/results_final.md`; все 5 сценариев проходят:

| Проверка | Результат | Требование |
| --- | --- | --- |
| VBAT при передаче, худший случай | 3.53 В | ≥ 3.4 В (EG800K) |
| Выброс VBAT при сбросе нагрузки | ≤ 3.97 В | ≤ 4.3 В |
| 3.3 В MCU при передаче | ровно 3.3 В | не проседает |
| Задержка входов NO / NC | 1.3–2.2 мс | < 3 мс |
| Спайк 0.2 мс | 2.2 В / 0.2 В на входе MCU | не доходит до порога |
| Датчик пропадания 12 В | 0.3 мс | раньше, чем MCU потеряет питание |
| MCU после пропадания 12 В | 47–51 мс до 2.7 В | ≥ 3 мс на запись FRAM |

При заказе монтажа на JLCPCB проверить в их предпросмотре повороты деталей — у библиотек KiCad и
JLCPCB бывает расхождение на 90/180° (особенно у EL817, SOT-23, SIM-держателя, модема). Модем EG800K-EU
на складе JLCPCB почти отсутствует — его поставлять давальчески (дистрибьютор Quectel).

## Что проверяется только на пилоте

- реальные импульсы TB74 / VN-5 / EU-9 (осциллограф), шум у соленоида;
- VBAT при реальной передаче EG800K и частота среза LMR16020 с 1410 мкФ;
- уровень сигнала антенны в металлическом корпусе, подбор C28/C29;
- типы разъёмов акцепторов для Y-жгута.

## Как пересобрать

```bash
cd hardware
python3 check_design.py      # design.py сверяется с библиотеками
python3 gen_sch.py           # схема
python3 gen_pcb.py           # расстановка
python3 route.py             # трассировка: ручные цепи + Freerouting

python3 gen_bom.py 500       # перечень с ценами → docs/
```

Разводка сделана автоматически по правилам из задания; решения, которые стоит посмотреть на ревью:

- линия антенны — 1.0 мм с зазором 0.2 мм до земли (≈ 54 Ом на FR4 1.6 мм), длина ~8 мм; П-цепь
  R26/C28/C29 у самого разъёма;
- силовая петля LMR16020 (вход → SW → дроссель → диод → земля) — самая короткая, какую позволила
  расстановка; стоит проверить глазами ширину и путь земляного возврата D3;
- земля верхнего слоя разрезана сигнальными дорожками на куски, каждый сшит с цельной землёй нижнего
  слоя переходными отверстиями (всего ~250).
