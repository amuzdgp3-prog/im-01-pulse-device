# ИМ-01 — устройство учёта импульсов для игровых аппаратов

Отдельный модуль к системе обслуживания аппаратов `2.apixspb.ru`. Устройство слушает импульсные
выходы монетоприёмника и купюроприёмника, копит показания в FRAM и дважды в сутки передаёт их на
сервер по LTE Cat.1. Показания идут **параллельно** ручным и в финансовую историю не пишутся.

Полное задание и спецификация: [docs/IM-01_FULL_BRIEF.md](docs/IM-01_FULL_BRIEF.md).

## Где что лежит

| Папка | Что там |
| --- | --- |
| `docs/` | задание, отчёты по шагам проверки, графики |
| `sim/` | аналоговая симуляция (ngspice): схемы, прогонщик, сводка результатов |
| `firmware/` | прошивка MCU (шаг 3, пока пусто) |
| `hardware/` | проект KiCad (шаг 5, пока пусто) |
| `server-contract/` | заметки по серверной части; сама реализация — в репозитории `2.apixspb.ru` (шаг 2) |

## Как повторить симуляцию

```bash
sudo apt-get install -y ngspice
python3 sim/run_sim.py        # ~1 минута; matplotlib — по желанию, для графиков
```

Результат — `sim/results_auto.md` и графики в `sim/out/`.
